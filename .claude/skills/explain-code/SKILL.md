# Explain code

1. Read the file or function I name.
2. Explain it top to bottom in plain English, grouping lines into small blocks. For each block say:
   what it does, why it is needed, and what would break without it.
3. Point out any line that is hard to justify or more complex than needed, and suggest a simpler version.
4. End with 3 questions someone reviewing this code might ask about it. Ask them one at a
   time and give feedback on my answers. Don't answer for me first.
